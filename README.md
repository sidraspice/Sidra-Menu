# عطارة سدرة بدمنهور — Web App
تم تحديث المشروع بالكامل بناءً على المتطلبات:
- استبدال التمرير الأفقي بـ CSS Responsive Grid للتصنيفات.
- إزالة سعر الكيلو وعرض أوزان التجزئة الفعلية فقط.
- إضافة نموذج بيانات العميل الإلزامي (الاسم، الهاتف، العنوان) وحقل الملاحظات.
- إضافة خطوة مراجعة الطلب قبل الإرسال.
- تجهيز رسالة WhatsApp المنظمة.
- حفظ السلة في LocalStorage وإضافة تأكيد مسح السلة.
